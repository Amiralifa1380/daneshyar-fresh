# دانش‌یار ۱.۲.۳ — نویسنده: امیرحسین فلاحتی

اپلیکیشن فارسی، بومی و آفلاین اندروید (Android 8/API 26 به بالا) با SQLite محلی و Material 3. شناسهٔ برنامه ir.daneshyar.offline حفظ شده، versionCode=6 است و دیتابیس از نسخهٔ ۱ به ۲ با اضافه‌کردن جدول پرونده‌های درسی و بدون حذف رکوردهای قبلی مهاجرت می‌کند.

## امکانات این آپدیت

- انتخاب تاریخ شمسی با چرخ سال، ماه و روز؛ تغییر روزهای مجاز با ماه و سال.
- انتخاب ساعت با ساعت گرافیکی ۲۴ ساعته. تاریخ، ساعت کلاس و مدت یادآوری دیگر نیاز به تایپ قالب ندارند.
- انتخاب مدت یادآوری از فهرست یا چرخ روز، ساعت و دقیقه؛ گزینهٔ خاموش هم وجود دارد.
- تنظیمات تم: هماهنگ با گوشی، روشن، تیره؛ رنگ اصلی آبی‌سبز، آبی یا بنفش.
- یک صدای مشترک برای همهٔ یادآوری‌ها، انتخاب زنگ گوشی یا فایل صوتی محلی.
- گزینهٔ تکرار صدا تا توقف دستی؛ سرویس پخش با اعلان فعال و دکمهٔ «توقف صدا». توقف از تنظیمات هم ممکن است.
- پروندهٔ هر درس: فایل‌های محلی، یادداشت‌های درس و لینک گروه/کانال.
- پشتیبان ZIP کامل شامل داده‌ها، جزوه‌ها، فایل صدای انتخابی و تنظیمات؛ JSON نسخهٔ قبلی همچنان قابل بازیابی است.
- مدیریت قبلی کلاس، استاد، نمره، واحد، معدل وزنی، رویداد و تقویم حفظ شده است.

## ساخت از مخزن مستقل daneshyar-fresh

این مخزن سورس را مستقیم می‌سازد. هیچ ZIP قدیمی در GitHub استخراج نمی‌شود.

۱. در GitHub یک مخزن خالی با نام daneshyar-fresh بسازید.
۲. بسته Daneshyar-Fresh-Repository.zip را روی کامپیوتر استخراج کنید. داخل پوشه daneshyar-fresh، پوشه UniversityAssistant و README.md را با Add file > Upload files آپلود و Commit کنید؛ خود ZIP یا پوشه بیرونی daneshyar-fresh را آپلود نکنید.
۳. با Add file > Create new file مسیر .github/workflows/android.yml را بسازید. تمام متن فایل جداگانه daneshyar-fresh-android.yml را در آن قرار دهید و Commit کنید. اگر پوشه .github همراه سورس قبلاً آپلود شده است، همین فایل را ویرایش کنید.
۴. Actions > Daneshyar Fresh 1.2.3 - Build and test APK > Run workflow را با variant=debug اجرا کنید.
۵. در Summary همان اجرا، خروجی Daneshyar-Fresh-APK-v1.2.3-debug-run-شماره را دانلود و استخراج کنید. فایل نصب Daneshyar-1.2.3-debug.apk است؛ build-info.json نسخه واقعی، هش و شماره اجرا را ثبت می‌کند.
۶. در صورت شکست، گزارش Daneshyar-Fresh-Reports-v1.2.3-run-همان شماره را ارسال کنید. وجود APK به تنهایی به معنی عبور تست‌ها نیست.

در ریشه مخزن باید UniversityAssistant/app/build.gradle و .github/workflows/android.yml موجود باشند. فایل‌های قبلی مخزن قدیمی را اینجا کپی نکنید.

این بسته سورس است و APK آماده داخل آن نیست. ساخت واقعی APK و تست اندروید هنوز انجام نشده‌اند. ساخت GitHub به اینترنت نیاز دارد؛ اجرای برنامه روی گوشی آفلاین است.

مخزن جدید از نظر سورس مستقل است؛ برنامه همان شناسه ir.daneshyar.offline را دارد. برای نصب به صورت آپدیت روی نسخه قبلی، همان کلید امضا لازم است. در مخزن جدید Secrets امضا خودکار منتقل نمی‌شوند؛ راهنمای UPDATE_SECURITY_FA.md را ببینید. پیش از تغییر نصب پشتیبان بگیرید.

## راهنمای استفاده

### تاریخ، ساعت و تم

فیلد تاریخ یا ساعت را لمس کنید تا انتخابگر باز شود. قالب تاریخ و ساعت خودکار ساخته می‌شود؛ ماه‌های شمسی و تعداد روز معتبر در انتخابگر رعایت می‌شوند. مدت یادآوری را هم لمس و از گزینه‌ها انتخاب کنید. تم و رنگ در تنظیمات قابل تغییرند و پس از بستن برنامه باقی می‌مانند.

### هشدار صوتی

در تنظیمات، «صدای مشترک همهٔ یادآوری‌ها» را باز کنید و زنگ گوشی یا فایل صوتی را انتخاب کنید. با «پخش آزمایشی» امتحان و سپس با «توقف صدای هشدار» قطع کنید. اگر گزینهٔ «تکرار صدا تا زدن دکمهٔ توقف» روشن باشد، MediaPlayer صدا را در سرویس پخش حلقه می‌کند. همهٔ هشدارها همین صدا را دارند؛ هشدار هم‌زمان چند پلیر جدا ایجاد نمی‌کند.

برای هشدار خودکار در پس‌زمینه:

- مجوز اعلان را در تنظیمات فعال کنید.
- در Android 12 به بالا، «اجازهٔ هشدار دقیق» را فعال کنید. برنامه بدون این مجوز از هشدار غیردقیق استفاده می‌کند؛ ممکن است برای شروع صدا نیاز به لمس اعلان باشد.
- حجم صدای Alarm گوشی را بالا ببرید. برنامه آن را به زور تغییر نمی‌دهد.
- برای توقف، دکمهٔ «توقف صدا» در اعلان فعال یا تنظیمات را بزنید.

تکرار نامحدود در کد، تضمین ادامهٔ پخش در هر وضعیت سیستم نیست. تماس و تغییر audio focus، خاموش‌شدن/راه‌اندازی گوشی، Force Stop، لغو مجوز و محدودیت باتری/سازنده می‌توانند صدا را متوقف یا محدود کنند. سرویس پخش از BOOT_COMPLETED اجرا نمی‌شود؛ پس از روشن‌شدن گوشی فقط یادآوری‌های آینده بازتنظیم می‌شوند. برنامه امنیت، DND و کنترل صوتی سیستم را دور نمی‌زند. پس از Force Stop برنامه را دوباره باز کنید.

### پروندهٔ درس

در دروس، زیر هر درس «پروندهٔ درس» را بزنید. «افزودن فایل»، «لینک» و «یادداشت» مستقل هستند. فایل از حافظهٔ گوشی به فضای خصوصی برنامه کپی می‌شود؛ این کار آپلود اینترنتی نیست و بعد از حذف فایل اصلی هم نسخهٔ داخل برنامه باقی می‌ماند. هر فایل حداکثر ۲۵ MiB است. PDF، تصویر، فایل Office و سایر فایل‌ها با برنامهٔ مناسب نصب‌شده روی گوشی باز می‌شوند؛ نمایشگر تمام فرمت‌ها داخل این اپ نوشته نشده است.

لینک‌ها با http یا https و نام میزبان معتبر پذیرفته می‌شوند؛ لینک t.me یا WhatsApp را وارد کنید. قبل از بازشدن، تأیید گرفته می‌شود و لینک در مرورگر/برنامهٔ دیگر باز می‌شود. ذخیرهٔ لینک آفلاین است؛ استفاده از گروه/کانال ممکن است به اینترنت همان برنامهٔ خارجی نیاز داشته باشد. دانش‌یار مجوز اینترنت ندارد.

ویرایش هر مورد، تغییر عنوان/متن و حذف را فراهم می‌کند. حذف درس، پرونده‌های وابسته را هم حذف می‌کند. برای مطالب بلند، فایل اضافه کنید؛ متن یادداشت تا ۴۰۰۰ نویسه است.

### پشتیبان و حفظ اطلاعات

خروجی جدید ZIP است و جزوه‌ها، یادداشت، لینک، نمره، کلاس، رویداد و تنظیمات را شامل می‌شود. صدای انتخاب‌شده از فایل هم همراه پشتیبان است؛ صدای سیستمیِ گوشی دیگر ممکن است موجود نباشد و در آن حالت صدای پیش‌فرض استفاده می‌شود. بازیابی JSON نسخهٔ قدیمی فقط اطلاعات قدیمی را دارد و پرونده‌های جدید را جایگزین/خالی می‌کند؛ قبل از بازیابی پشتیبان کامل تهیه کنید.

هر فایل تا ۲۵ MiB، اطلاعات JSON تا ۱۰ MiB، مجموع بازشدهٔ ZIP تا ۳۰۰ MiB و هر جدول تا ۱۰٬۰۰۰ رکورد پذیرفته می‌شود. مسیر و اندازهٔ ورودی ZIP بررسی می‌شود. فایل‌ها قبل از تغییر دیتابیس آماده می‌شوند و جایگزینی رکوردها در تراکنش است؛ ZIP ناقص نباید داده‌ها و فایل‌های قبلی را پاک کند. پشتیبان رمزگذاری نشده است و باید در محل امن و محلی ذخیره شود.

برای آپدیت بدون حذف نصب، کلید امضای APK جدید باید همان کلید قبلی باشد. افزایش versionCode و مهاجرت دیتابیس این شرط امضا را حذف نمی‌کنند. برنامه را بدون پشتیبان پاک نکنید. تصویر هشدار Play Protect قبلی، توسعه‌دهندهٔ ناشناخته را نشان می‌دهد؛ امضای ثابت و انتشار مناسب کمک می‌کنند ولی حذف قطعی هشدار یا امنیت همیشگی تضمین نمی‌شود.

## ساخت محلی و کد

JDK 17، Gradle 8.9، Android SDK API 35 و Build Tools 35.0.0 لازم است. ANDROID_HOME را تنظیم کنید. AGP 8.7.3، Material Components 1.12.0 و AppCompat 1.7.0 برای ساخت دانلود و داخل APK بسته‌بندی می‌شوند؛ اجرای برنامه به سرویس/API اینترنتی وابسته نیست.

```bash
bash build-apk.sh
# با اطلاعات کلید در محیط از قبل تعریف‌شده:
BUILD_VARIANT=release bash build-apk.sh
python3 tests/host_checks.py
bash run-android-tests.sh
```

Gradle Wrapper باینری داخل بسته نیست؛ با Gradle نصب‌شده، gradle wrapper --gradle-version 8.9 آن را ایجاد می‌کند. --offline فقط پس از آماده‌بودن کش کامل وابستگی‌ها و SDK قابل استفاده است.

| ماژول | مسئولیت |
| --- | --- |
| MainActivity / UiParts | رابط فارسی Material، فرم‌ها و صفحهٔ پرونده |
| Pickers | تاریخ شمسی، ساعت و مدت انتخابی |
| AppPrefs | تم، رنگ، صدای مشترک و وضعیت هشدار |
| AlarmService / StopAlarmReceiver | پخش حلقه‌ای، audio focus و توقف صریح |
| Store | SQLite نسخهٔ ۲، مهاجرت و CRUD |
| LocalMaterials | کپی خصوصی فایل، لینک و FileProvider محدود |
| BackupFiles | ZIP کامل با محدودیت اندازه و مسیر امن |
| PersianDates / Reminders / Receiverها | تقویم و زمان‌بندی محلی |

## وضعیت آزمون

۷۰ assertion منطق Java/نام فایل، ۳۵ بررسی میزبان و تجزیهٔ نحو ۱۴ فایل Java موفق شدند. این‌ها بررسی نوع‌های Android، Lint واقعی یا تست دستگاه نیستند. یک مجموعهٔ Instrumentation با ۳۹ assertion برای مهاجرت، فایل/یادداشت، پشتیبان ZIP و JSON قدیمی، انتخابگرها، صفحه‌ها و شروع/توقف سرویس هشدار نوشته شده ولی در این محیط اجرا نشده است.

روی شبیه‌ساز یا گوشی آزمایشی اجرا کنید؛ آزمون دیتابیس و فایل در فضاهای جداگانه‌اند، ولی برای آزمون پخش، سرویس واقعی برنامه موقتاً شروع و متوقف می‌شود. تست دستی روی گوشی برای پخش واقعی، اعلان پس‌زمینه، خواب دستگاه، تم‌ها، انتخابگرها، برنامهٔ نمایش PDF و نصب آپدیت با کلید ثابت لازم است.

## اصلاح ۱.۲.۳

کرش راه‌اندازی از فراخوانی Window.getInsetsController قبل از ساخت DecorView بود. تنظیم نوارها بعد از setContentView انجام و controller از View آماده خوانده می‌شود، با بررسی null و تلاش پس از اتصال پنجره. نام ZIP و workflow تغییر نکرده‌اند تا فقط جایگزینی ZIP کافی باشد. اصلاح در میزبان بررسی شده؛ نتیجهٔ اجرای مجدد آزمون اندروید هنوز دریافت نشده است.
