# گزارش آزمون — ۲۰۲۶/۱۰/۱۴

## موفق در محیط میزبان

- ۶۱ assertion روی کد Java استخراج‌شده از توابع واقعی ascii، minutes، clock، digits و nextSession: ارقام فارسی/عربی، ساعت نامعتبر، انتقال به هفتهٔ بعد، عبور یادآوری از نیمه‌شب، همهٔ ۴۹ ترکیب روز مبدأ/مقصد و تغییر ساعت تابستانی.
- ۱۶ بررسی اسکیمای SQLite، XML و عدم وابستگی شبکه: ایجاد چهار جدول، ذخیرهٔ نمره، محدودیت نمره و واحد، روز نامعتبر، پایان پیش از شروع، کلید خارجی، نوع رویداد، برگشت تراکنش خراب، حذف استاد/درس با روابط مورد انتظار، مقادیر پارامتری، XML معتبر، نبود مجوز اینترنت و نبود فراخوانی شبکه در Java.
- تجزیهٔ نحو ۷ فایل Java شامل آزمون اندروید با JavaCompiler.parse موفق بود. این کار بررسی نوع با android.jar یا کامپایل Android نیست.
- نگاشت اشتباه شنبه در نخستین اجرای آزمون منطق شناسایی، اصلاح و همهٔ آزمون‌ها دوباره اجرا شدند.

## انجام‌نشده / مسدود

- اجرای build-apk.sh: به علت نبود Gradle متوقف شد.
- Android SDK، platform/build-tools، android.jar، adb و شبیه‌ساز در محیط موجود نبود.
- تلاش برای دریافت Android Build Tools از dl.google.com و ابزار از Maven با HTTP 403 مسدود شد.
- بنابراین APK تولید یا امضا نشده است؛ Lint، کامپایل Android و نصب اجرا نشده‌اند.
- آزمون‌های Instrumentation نوشته شده‌اند اما اجرا نشده‌اند.
- رفتار واقعی اعلان، سازگاری دستگاه‌های مختلف و نمایش رابط روی دستگاه تأیید نشده‌اند.

این گزارش فقط شواهد اجراشده را بیان می‌کند؛ موفقیت میزبان اثبات اجرای کامل برنامه روی اندروید نیست.

## پیگیری اجرای GitHub توسط کاربر

- طبق لاگ ارسالی کاربر در ۱۴ اکتبر ۲۰۲۶، assembleDebug تکمیل شد؛ سپس lintDebug به خاطر android:windowLightNavigationBar با minSdk 26 شکست خورد.
- تنظیم مذکور به values-v27 منتقل و برای API 26 پس‌زمینه مناسب آیکون روشن تعیین شد؛ حداقل نسخه اندروید همان API 26 است.
- دو بررسی منابع نسخه‌بندی‌شده به تست میزبان اضافه شدند (مجموع ۱۸ بررسی، به‌علاوه ۶۱ assertion منطق Java و بررسی نحو ۷ فایل).
- setup-android در workflow داخل بسته نیز از v3 به v4 تغییر کرد تا بسته حذف‌شده tools درخواست نشود.
- اجرای مجدد ساخت، Lint و تست اندروید پس از این اصلاح هنوز تأیید نشده است. گزارش اولیهٔ بالا مربوط به محیط تولید پروژه بود.

## پیگیری توقف runner آزمون

- لاگ بعدی کاربر نشان داد APK آزمون هم کامپایل شده، ولی Instrumentation code: 0 و صفر آزمون گزارش شده است. این لاگ به‌تنهایی stacktrace علت اصلی را ندارد.
- در بررسی کد، Context بستهٔ آزمون برای دیتابیس استفاده شده بود؛ اصلاح شد تا Context هدف با نام جداگانهٔ دیتابیس آزمون استفاده شود.
- ثبت شروع آزمون پیش از setup و ثبت stacktrace کامل و شکست استاندارد آزمون اضافه شد. runner به‌جای لغو با کد صفر، پایان اجرای Instrumentation را جدا از موفقیت/شکست آزمون اعلام می‌کند.
- نتیجهٔ واقعی اجرای دوباره هنوز دریافت نشده؛ علت قطعی توقف قبلی فقط با stacktrace قابل تأیید است.

## نسخهٔ ۱.۱ — بازطراحی و امضای انتشار

- رابط به Material 3 و AppCompat، با کتابخانه‌های بسته‌بندی‌شدهٔ 1.12.0 و 1.7.0 تغییر یافت؛ هیچ فراخوانی شبکه یا مجوز اینترنت در سورس برنامه اضافه نشد.
- نام نویسنده: امیرحسین فلاحتی. شناسهٔ برنامه ثابت، versionCode=2، دیتابیس نسخهٔ ۱ حفظ شد.
- ۶۱ assertion منطق، ۲۴ بررسی میزبان و بررسی نحو ۸ فایل موفق بودند. اسکریپت‌های Bash و ساختار YAML نیز بررسی شدند.
- آزمون Android اکنون یک مجموعه با ۲۳ assertion شامل صفحه‌های Material و نام نویسنده است؛ هنوز اجرا نشده است.
- ساخت release با کلید بیرونی، جلوگیری از خروجی release بدون امضا، بررسی apksigner و manifest نهایی در workflow اضافه شد؛ این بررسی‌های APK در محیط محلی اجرا نشده‌اند، چون APK جدید ساخته نشده است.
- نصب روی نسخهٔ قبلی به اصل کلید امضای قبلی وابسته است و بدون آن تأیید/تضمین نمی‌شود. امنیت همیشگی یا حذف تمام هشدارهای Play Protect تضمین نشده است.
- نتیجهٔ واقعی کامپایل، Lint، نمایش بصری و تست دستگاه نسخهٔ ۱.۱ هنوز باید از GitHub دریافت شود.

## نسخهٔ ۱.۲ — انتخابگرها، صدا، تم و پروندهٔ درسی

- versionCode=3، دیتابیس نسخهٔ ۲ با مهاجرت ۱→۲ و جدول resources. پنج جدول واقعی با SQLite میزبان بررسی شدند.
- ۷۰ assertion منطق Java و محدودیت نام فایل، ۳۵ بررسی میزبان و تجزیهٔ نحو ۱۴ فایل Java موفق شدند؛ اسکریپت Bash و YAML جدید بررسی شدند.
- انتخابگرهای غیرتایپی، DayNight، صدای مشترک، سرویس mediaPlayback با توقف صریح، فایل‌های خصوصی، لینک خارجی تأییدشده و پشتیبان ZIP محدود به مسیر/اندازه پیاده شده‌اند.
- آزمون Instrumentation با ۳۹ assertion شامل مهاجرت، ZIP فایل‌ها، رد پشتیبان ناقص، JSON قدیمی، رابط/انتخابگرها و شروع/توقف سرویس آماده شده است.
- **کامپایل Android، Lint، پخش واقعی، رفتار foreground در پس‌زمینه و تست‌های دستگاه نسخهٔ ۱.۲ هنوز اجرا/تأیید نشده‌اند.** وجود مؤلفه‌ها در سورس اثبات اجرای موفق روی گوشی نیست.
- هشدار ارسالی Play Protect دربارهٔ ناشناخته‌بودن توسعه‌دهنده بود؛ حذف قطعی هشدار و امنیت همیشگی ادعا نشده است. تصاویر شخصی کاربر داخل بسته قرار نگرفته‌اند.

## اصلاح ۱.۲.۱ براساس خطای واقعی اجرا

- لاگ ارسالی کاربر NullPointerException در MainActivity.render هنگام Window.getInsetsController و راه‌اندازی Activity را نشان داد.
- تنظیم نوارهای سیستم به پس از setContentView منتقل، View آماده گرفته شده و controller با null guard و تلاش پس از attachment استفاده می‌شود؛ خواندن مستقیم از Window حذف شد.
- versionCode=4 و versionName=1.2.1؛ دیتابیس و نام ZIP/workflow ثابت‌اند.
- بررسی‌های میزبان شامل دو بررسی ترتیب آماده‌شدن View اضافه شده‌اند. تست راه‌اندازی موجود روی Android باید دوباره اجرا شود؛ موفقیت واقعی اصلاح روی دستگاه هنوز تأیید نشده است.
